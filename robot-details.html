Self-Balancing Autonomous Robot

Category: Embedded Systems & Control Loops | Timeline: June 2026
[ Hardware Prototyping Photo Placement ]

Project Overview

This project focused on the mechanical construction, circuit design, and firmware tuning required to achieve autonomous active balance on a two-wheeled inverted pendulum chassis. Powered by an ESP32 microcontroller, the vehicle monitors tilt angles dynamically and drives independent motors to correct orientation deviations instantly.

Technical Breakdown

  • Microcontroller Core: Programmed an ESP32 framework within the Arduino IDE environment to enable fast execution loops for processing sensor inputs and writing PWM signals.
  • Actuation & Electronics: Configured dedicated hardware lines to coordinate stepper motor modules and micro servos, managing power constraints on a structured breadboard architecture.
  • Control Feedback: Tuned software response calculations to minimize lag, ensuring smooth tracking transitions and keeping the system perfectly upright under shifting manual loads.

Key Challenges Faced

The primary engineering hurdle involved dampening electrical noise within the custom breadboard circuitry. Isolating the power supply going to the motor controllers from the logic line feeding the ESP32 dramatically increased control loop reliability and prevented sudden sensor spikes.
